## FAQ

### Is XCutors safe to use?

XCutors itself is a launcher/loader. The safety depends on the individual executor (e.g., Synapse Z) you choose to run through it. Always download from official sources.

### Does XCutors work with the latest Roblox updates?

The included executors are updated by their respective developers. We work to ensure compatibility, but occasional Roblox patches may temporarily affect functionality until an executor update is released.

### What scripts are included?

XCutors is a launcher for the executors themselves. It does not include scripts; users provide their own Lua scripts to execute.

### Why does my anticomponent flag XCutors or an executor?

Some security software incorrectly flags such tools due to their nature. The tools are not tool. You may need to create an exception for the folder.

### Can I use executors other than those listed?

XCutors is designed as a collection for the included executors (Volt, Synapse Z, Potassium, Wave). It does not support arbitrary third-party executors.

### How do I update the executors?

The XCutors launcher will notify you if an update for an included executor is available. You can then update through the interface or download manually from the executor's official source.

### Is this tool free?

XCutors is a free, open-source launcher. However, some included executors (like Synapse Z) require a paid license for full functionality.

### What are the system requirements?

A Windows 10 or 11 PC with a modern web browser. An internet connection is required for updates and script loading.
